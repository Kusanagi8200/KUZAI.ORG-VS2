# `Assistant result reports`

GOGIT stores:
- `latest.json` --> latest published sanitized command result
- `history/<STEP_ID>.json` --> immutable result history

The repository is public. Reports must contain no credentials, tokens, private keys, cookies, private data or secret configuration.

See [tools/GOGIT.md](../../tools/GOGIT.md).
