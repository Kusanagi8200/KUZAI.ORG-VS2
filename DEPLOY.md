## SECURITY CHECKS

Check HTTPS headers:

curl -I https://kuzai.org/

Check that Git metadata is blocked:

curl -I https://kuzai.org/.git/config

Expected result:

403 Forbidden

Check that app config is not public:

curl -I https://kuzai.org/app/config.php

Expected result:

404 Not Found or 403 Forbidden

## PUBLIC CHECKS

Check HTTP redirect:

curl -I http://kuzai.org/

Expected result:

301 Moved Permanently

Check HTTPS:

curl -I https://kuzai.org/

Expected result:

200 OK

Check page content:

curl -s https://kuzai.org/ | grep -E "KUZAI LOCAL AI|OWNING THE FULL STACK"
